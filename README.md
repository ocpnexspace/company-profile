# Company Profile Web Application

This repository contains the official **Company Profile** web application for **OCP Nexspace**. It showcases the company’s services, projects, team, pricing plans, testimonials, and FAQs in a modern, responsive, and interactive web interface.

Built with **React**, **Tailwind CSS**, and **Framer Motion**, this project demonstrates the company's digital presence, innovation, and client-centric approach.

---

## Features

- Hero section with animated headlines and call-to-action buttons  
- Services, Features, and How-It-Works sections  
- Team and Testimonials showcase  
- Pricing plans with interactive cards  
- FAQ section with accordion animations  
- Newsletter subscription integration  
- Fully responsive design for desktop and mobile devices  
- Light/Dark mode support  
- Smooth scroll and scroll-triggered animations for enhanced UX  

---

## Tech Stack

- **React**: Component-based architecture for scalable UI  
- **Tailwind CSS**: Utility-first CSS for responsive styling  
- **Framer Motion**: Smooth animations and scroll effects  
- **Radix UI / Shadcn UI**: Accessible UI components  
- **TypeScript**: Type safety and better maintainability
